Goal ^rAhDavxt

We want to simulate a real small network: ^zEs0POpS

Client_VM → Router_VM → VirtualBox NAT → Host → ISP Router → Internet ^frYH1Fzu

Router_VM = acts as a router with NAT and optional DHCP.
Client_VM = connects to the Internet only through the router.
VirtualBox NAT = represents your host’s connection to the Internet. ^zbo1J5LS

First we setup the VirtualBox Network configuration ^CgyOO9Ot

* The NAT adapter gives Router_VM Internet access through your host (via VirtualBox’s internal NAT router).

* The Internal Network allows both VMs to talk to each other privately (like a LAN).

* The name intnet must match exactly on both. ^ArXrzBDB

After booting Router_VM, you’ll typically see two interfaces: ^X9MosGcl

Now we need to give Router_VM Internal Interface (enp0s8) a Static IP. ^w5p4Ikxm

Router_VM ^hwLIRv38

sudo ip addr add 192.168.56.1/24 dev enp0s8
sudo ip link set enp0s8 up ^00WHzqaB

We run: ^QkrvIPvM

This IP will be the gateway for your Client_VM.

To verify run: ^je102jVg

ip a show dev enp0s8 ^aLzKpnsk

You can make those interface configurations permanent by editing the network setup file on the Router_VM instead of typing ip addr add and ip link set up every boot. ^NRcah0L0

Open the configuration file: ^XBTSGiu3

/etc/network/interfaces ^0xASba5a

add: ^taDFADDp

# Internal network interface (connected to "intnet")
auto enp0s8
iface enp0s8 inet static
    address 192.168.56.1
    netmask 255.255.255.0 ^AFXEu1Br

"auto" means bring the interface up automatically on boot.

iface enp0s8 inet static → gives the internal network interface a static IP (the one that will act as a gateway for the client).

Save, then apply changes: ^Un2syxTk

sudo systemctl restart networking ^xREIMVk9
